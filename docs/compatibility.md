## Status definitions

- **Working** — activation confirmed and no known blocking issue.
- **Partial** — works with a documented limitation.
- **Broken** — reproducible failure.
- **Untested** — not a compatibility claim.

## Minimum report data

Every compatibility result should include:

- game and version,
- GPU and architecture,
- driver version,
- distribution and kernel,
- Wine / Proton version,
- DXVK / VKD3D-Proton version if applicable,
- Vulkanized-Fakenvapi commit or release,
- configured backend,
- active backend,
- frame-generation state,
- relevant log excerpt.
